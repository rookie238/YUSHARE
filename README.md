# YuShare App - ACM431 Lab Project

## Team Members
-Hasan Uz 20201308020

Features
- **Menu Screen:** A dashboard with navigation options and a profile summary header.
- **Profile Management:** Users can view their name, bio, student ID, and department details.
- **Edit Profile:** A popup dialog that allows users to update their Name and Bio.
- **Firebase Integration:** Real-time data updates using Firebase Firestore / Authentication.
- **Modern UI:** Built fully with **Jetpack Compose**.

- Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Backend:** Firebase (Firestore & Auth)
- **Version Control:** Git & GitHub (Branching, Pull Requests, Issues)
